# AI 使用学习笔记

记录我在 AI 使用方面的学习过程与成果，最终沉淀为一个可复习、可回顾的知识站点。

## 学习方式（对话式）

学习在对话中发生，站点是学习成果的沉淀。完整闭环：

1. **选题**：按路线图顺序，或我提出想学的主题。
2. **引导学习**：AI 查找资料、讲解概念、出练习，在对话中互动。
3. **答疑纠正**：我提问、做练习，AI 点评并纠正理解偏差。
4. **生成页面**：一个主题学完后，AI 把对话成果整理成站点页面。
5. **复习回顾**：通过站点页面和复习清单自测，发现遗忘就回到对话补学。

## 目标

- **系统学习**：从提示词工程到 Agent、RAG、多模态，逐步建立完整的 AI 使用能力。
- **实践导向**：每个知识点都配套真实的使用记录和示例，不停留在概念层面。
- **可复习**：笔记结构统一、带复习清单，方便日后快速回顾。
- **可发布**：内容最终发布为静态站点，随时翻阅。

## 站点页面如何产生

页面不由手写。每轮对话学习结束后，AI 会把本次学到的内容按
`templates/note-template.md` 的结构整理成笔记，再生成对应的站点页面。
我只需要专注学习，以及在复习时提出"这页讲的不清楚，我们重新学"。
