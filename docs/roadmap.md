# 学习路线图

> 这是整个学习项目的总规划。每完成一个阶段，回来更新本文档的状态。

## 阶段一：提示词工程基础

**目标**：能写出清晰、可控的提示词，理解模型的能力与边界。

- 提示词的基本结构（角色、任务、上下文、输出格式）
- 常见技巧：few-shot、思维链、分步指令
- 结构化输出（JSON、表格、Markdown）
- 提示词的调试与迭代方法

## 阶段二：AI 编程助手高效使用

**目标**：熟练使用 AI 编程工具完成真实开发任务。

- 工具对比与适用场景（Codex、Copilot、Claude Code 等）
- 如何描述任务：需求拆解、上下文提供、约束声明
- 代码审查：如何验证 AI 产出的代码
- 与 AI 协作的工作流（分支管理、提交粒度、回滚策略）

## 阶段三：Agent 与工具调用

**目标**：理解 Agent 的工作原理，能搭建简单的自动化 Agent。

- Agent 的核心循环：感知 → 规划 → 执行 → 反馈
- 工具调用（Function Calling / MCP）
- 多 Agent 协作模式
- 实践：搭建一个自动完成某类任务的 Agent

## 阶段四：RAG 与知识库

**目标**：理解检索增强生成，能为自己的资料搭建问答能力。

- 嵌入（Embedding）与向量检索的基本原理
- 文档切分策略与检索质量
- 实践：把本项目的笔记做成可问答的知识库

## 阶段五：多模态应用

**目标**：掌握文本之外的 AI 能力。

- 图像生成与编辑
- 语音转写与合成
- 视频/文档理解

## 阶段六：自动化与工作流集成

**目标**：把 AI 能力嵌入日常工作流。

- 定时任务与自动化（提醒、监控、报告生成）
- 与常用工具集成（日历、邮件、文档）
- 复盘：整套学习成果的站点化整理
